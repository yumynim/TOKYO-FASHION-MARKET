# 案件

クライアントワークとしての**案件・依頼ごとの情報**を置くフォルダです。

- 依頼内容・契約範囲
- クライアントとのやり取り・決定事項
- 納期・スケジュール
- 個別案件ごとのメモ（複数案件がある場合はサブフォルダで分ける）

（移動すると参照リンクが壊れるため、現状は据え置き）:

- [`要件確認ヒアリングシート.docx`](../要件確認ヒアリングシート.docx)（クライアント記入用の仕様確定シート）
- [`指示テンプレート.txt`](../指示テンプレート.txt)（クライアント記入用の文章・写真収集テンプレート）
