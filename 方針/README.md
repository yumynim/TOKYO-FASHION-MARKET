# 方針

このプロジェクトにおける**意思決定・方向性・進捗**を記録するフォルダです。

- **方向性・意思決定**: 「なぜその仕様にしたか」「今後どちらの方向に進めるか」といった、
  コードの変更履歴だけでは残らない判断を記録する
- **進捗**: 現在地・やることリストの詳細な作業ログは [`docs/PROJECT_STATE.md`](../docs/PROJECT_STATE.md) が正。
  ここにはそれを踏まえた**もう一段上のマイルストーン管理**（フェーズの区切り、次に何を優先するか等）を置く
