# 素材

クライアント・関係者から受け取った**未加工の素材**（写真・文章・ロゴ元データ等）を置くフォルダです。

- サイトにまだ組み込んでいない写真・文章・ロゴの元データ
- 受け取ったままの状態のファイル（リサイズ・トリミング等の加工前）

## `資料/` フォルダとの違い

既存の [`資料/`](../資料/) フォルダには、サイトで実際に使っているロゴ画像等が入っています。
役割を分けています:

- **`素材/`（本フォルダ）**: 受け取ったまま・まだサイトに使っていない元データの置き場
- **`資料/`**: サイトのHTML/CSSから実際に参照している、使用確定済みの画像等

素材をサイトに組み込む際は、加工後のファイルを `資料/` または `img/` に置き、
`素材/` 側の元データはそのまま保管する運用とします。
